IR Block Planner (Chennai Division) is a browser-based tool that helps Indian Railways plan maintenance track closures with minimal disruption to trains. It uses an NSGA-II optimizer to find the best block windows, a live map simulation to check for conflicts, and an overrun predictor to estimate risk. It also auto-generates the Form T/369 block requisition memo, which is normally filled in by hand.

Built with HTML, JavaScript, Leaflet and Chart.js.
